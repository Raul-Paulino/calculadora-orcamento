# 🧁 Sistema de Orçamento - Confeitaria Flor de Liz

Um sistema web moderno e responsivo desenvolvido para automatizar e agilizar o cálculo de orçamentos de uma confeitaria real. O projeto resolve um problema prático do dia a dia, permitindo calcular o valor unitário a partir do cento, somar itens de diferentes categorias (Doces, Bolos e Salgados) e gerar um resumo organizado pronto para envio direto via WhatsApp.

---

## 🚀 Funcionalidades

- **Carrinho Unificado (Multi-páginas):** Permite navegar entre Doces, Bolos e Salgados somando os itens ao orçamento geral usando o `localStorage` do navegador.
- **Cardápios Dinâmicos:** 
  - *Doces e Salgados:* Cálculo automático do valor unitário por cento e multiplicação por quantidade unitária.
  - *Bolos:* Seleção de fatias, massas, recheios (em caixas de seleção) e campo personalizado para o **Tema / Decoração**.
- **Resumo Organizado por Tópicos:** Separa os itens claramente por seções com emojis para facilitar a leitura do cliente.
- **Botão Copiar p/ WhatsApp:** Formata e copia o orçamento completo direto para a área de transferência com um clique.
- **Design Responsivo (Mobile-First):** Otimizado para ser acessado e utilizado facilmente pelo celular no atendimento aos clientes.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído do zero utilizando as tecnologias fundamentais do desenvolvimento web:

- **HTML5:** Estruturação semântica das páginas de cardápio e resumo.
- **CSS3:** Estilização personalizada com a identidade visual da confeitaria, Flexbox e Media Queries para responsividade.
- **JavaScript (ES6+):** Lógica de cálculo, manipulação do DOM e persistência de dados com `localStorage`.
